# Collective Memory messages: localization review

- Date: 2026-11-08
- Role: localization-reviewer (`.kiro/agents/localization-reviewer.md`, read in full before reviewing). Read-only. This is the only file written; no message, code or test file was changed.
- Reviewed: `Memory` namespace of `apps/web/messages/{en,tr,de,fr,es}.json`, 39 messages each: `Memory.screening`, `Memory.attribution`, `Memory.meddra` and 36 `Memory.codes.*`. The API has 37 canonical sentences (`apps/api/janus/memory/messages.py`); `screening_statistic` is the sentence stored as `Memory.screening`, so the 36 codes plus `screening` make the 37 entries. Key sets are identical in all five files and match the API.
- Also read: `.kiro/steering/medical-safety.md` (via role file), `apps/web/src/i18n/forbidden-phrases.ts`, `apps/web/src/i18n/memory-words.ts`, `fr.json` line 4 (existing French term for "pattern").
- Scope: english is the source. Placeholders `{first}`, `{last}`, `{share}`, `{date}` are untouched in every current string and in every replacement below.

## Summary

- 16 blocking fixes, 14 advisory fixes, 13 doubtful OKs (rows below). Every other string is OK and is not listed.
- Blocking: French "motif" (false friend, 7 strings); Turkish "payda" (reads as denominator, 2 strings); Turkish and German "no effect" readings in `combination_caveat` (false reassurance, DE blocking, TR/FR/ES advisory); Turkish "FDA onayı" (approval vs endorsement); Turkish safety lines (ungrammatical clause, "acil servis" means the hospital emergency department); German "Türkei" instead of "Türkiye" in the three safety lines.
- The three safety lines are calm and non-diagnostic in all languages. They keep 112 and 911 exactly, once each, in every language. They do not tell anyone to start, stop or change a medicine.
- `Memory.screening`: the causal word is present only as the negated claim in all five languages (see rows). All five equal the `allowedScreening` strings in `memory-words.ts`. Any edit to it must be made in `allowedScreening`, `messages.py` and the json together.
